# AgendaLocal - Prototipo estático

Este proyecto corresponde a la primera fase del sitio de recordatorios.

## Ruta estática
La página principal se sirve como archivos estáticos:
- index.html
- css/style.css
- js/app.js

## Objetivo de esta fase
- Definir la interfaz visual.
- Mostrar calendario.
- Mostrar recordatorios de ejemplo.
- Mostrar notas de ejemplo.
- Mantener el sitio funcional sin depender de Internet.
- Preparar una base estable para la futura ruta dinámica.

## Próxima fase
La ruta dinámica podrá incorporar PHP + PostgreSQL para:
- Crear recordatorios.
- Listarlos.
- Editarlos.
- Eliminarlos.
- Crear y editar notas.
- Persistir la información.
