# AgendaLocal — V2 corregida

Cambios:
- Tema nocturno y tema día con un solo botón.
- Navegación entre vistas.
- Calendario con cambio de meses.
- Selección de días y eventos de demostración.
- Botones "Nuevo recordatorio" y "Nueva nota" muestran un `window.alert()` real.
- La alerta explica que esas funciones pertenecerán a la ruta dinámica PHP + PostgreSQL.
- Sin dependencias externas de Internet.
